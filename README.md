# SendCart 🛍️
Mobile-first WhatsApp and social commerce platform and ordering platform built for social commerce vendors in Nigeria.

🔗 **Live Demo:** [sendcart.vercel.app](https://sendcart.vercel.app)

## Features
- **Mobile Storefront:** Categorized product catalog with Naira (₦) pricing, item variants, and real-time stock counters.
- **Instant WhatsApp Checkout:** Generates itemized order details and bank transfer instructions directly into a vendor chat.
- **Vendor Dashboard:** Catalog management, custom delivery zones (Lagos Mainland / Island / Outside Lagos), and bank account settings.
- **Order Management:** Track incoming orders across statuses (Pending, Paid, Dispatched, Delivered).

## Tech Stack
- **Frontend:** React, TypeScript, Tailwind CSS
- **Database & Backend:** Supabase, Drizzle ORM
- **Deployment:** Vercel
